# Poster

A0 portrait poster (841 × 1189 mm) for the 2nd dAIversity Conference, in Polish.

- `poster-pl.dc.html`: poster source, 3178 × 4494 px at 96 px/in.
- `poster-pl-preview.png`: rendered preview.
- `qr-repo.svg`: QR code to this repository (error correction level M, version 5), checked by
  decoding it from the rendered poster.

Figures come from `../code/poster_figs.py --lang pl` applied to `../data/main/analysis/results.json`,
with no additional computation. Typeface: IBM Plex Sans (SIL Open Font License), converted to outlines
in the SVG figures. Every number on the poster comes from `../data/main/analysis/RESULTS.md` and
`INTERPRETATION.md`.

The "[WYNIK 25.10]" placeholder marks the result of amendment 02, which will be filled in after that
data collection.
